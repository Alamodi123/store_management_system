🏬 Store Management System 
A robust Django-based backend designed for efficient inventory and customer relationship management. This project serves as a centralized API for handling store operations, featuring a modular architecture with dedicated apps for customers and products.

🔗 GitHub Repo:

📌 Project Overview
This system was built to solve the challenges of manual inventory tracking by providing a structured database and a set of RESTful endpoints to manage store data. It leverages Django's powerful ORM to ensure data integrity across complex relationships between products and customers.

🧰 Tech Stack
Backend: Django (Python)

Database: SQLite (Development) / PostgreSQL (Production ready)

Architecture: Modular App-based Design

Tools: Git, GitHub, Django Admin

🧠 Technical Highlights
Python, Django, SQLite, Django REST Framework

Architected a modular backend with independent applications for customers and products, ensuring high maintainability and a clean separation of concerns across the system.

Developed a secure management interface using the Django Admin suite, allowing store administrators to perform full CRUD operations on inventory and user records with built-in authentication.

Engineered a relational database schema that tracks product details and customer interactions, utilizing Django's ORM for optimized query performance and seamless data migrations.
